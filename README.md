# 2027 CID 第 32 屆國際設計學術研討會網站

多頁響應式網站，使用原生 HTML、CSS 與 JavaScript。可直接開啟 `index.html`，或在此資料夾執行 `python3 -m http.server 4173` 後預覽。

正式網站：https://cid2027-ntut.github.io/cid-32-symposium-2027/

## 頁面

- `index.html`：大會摘要、重要日期與主要入口
- `about.html`：大會主題、與新一代設計展的連結及組織單位
- `call-for-papers.html`：六大徵稿子題、投稿、審查與發表規範
- `speakers.html`：已公布講者與工作坊流程
- `program.html`：工作坊與 2027 年 5 月 22 日研討會議程
- `venue.html`：北科大場地、交通與無障礙資訊狀態
- `registration.html`：報名費率、報名政策與聯絡資訊

全站提供繁體中文／英文切換，並保留手機導覽與語意化議程表格。
